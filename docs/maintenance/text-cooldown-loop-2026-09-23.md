# 小象助手文字计时闭环

2026-09-23：语音识别、麦克风和播报暂缓。本次实现文字输入到计时显示。

## 使用

启动或重启独立监控服务（`start-monitor.ps1`），进入整屏监控页面，点击“打开置顶小面板”。已有悬浮面板刷新后可见“小象助手 · 文字计时”。仅使用文字计时可暂停屏幕监控；文字计时不依赖阵容或画面识别。

也可先在浏览器访问 `http://127.0.0.1:8767/monitor/panel?panel=1&monitor=off` 检查文字计时。

输入“妲己放大了”“孙悟空闪现了”或带“小象助手”前缀的同类指令。大招和闪现可同时保留；同英雄同技能再次登记会替换旧计时。朵莉亚等未知冷却显示“已记录释放，冷却未知”。使用基础冷却估算，以记录时点计时。

小于等于 5 秒显示即将可用，到期保留“预计已转好”卡片和文字提醒。支持单项移除、清空、新计时对局。输入文字时需要主动聚焦面板；本次未增加 Windows 鼠标穿透或防激活功能。

## 保存与接口

文字计时使用独立对局编号，浏览器 localStorage 保存编号，SQLite 保存记录与绝对到期时间。相同浏览器配置和服务地址刷新后可恢复；清除浏览器存储会丢失该对局入口。计时每 3 秒同步一次，浏览器休眠后按当前时间重新计算。

主工作台与独立监控共用 `gameplan/web/timer_routes.py`，独立监控首次请求计时接口时才加载存储。主工作台继续支持原 WebSocket 同步。

- `POST /api/matches/{match_id}/text-command`，JSON：`{"text":"妲己放大了"}`。
- `GET /api/matches/{match_id}/skill-timers`，恢复活动记录和历史。
- `POST /api/matches/{match_id}/skill-timers/{timer_id}/cancel`，移除单项。
- `POST /api/matches/{match_id}/skill-timers/clear`，清空活动记录，保留历史。

语音文字接口仍要求唤醒词。没有接入语音服务，也不需要 API Key。

## 验证范围

后端测试覆盖两个服务的文字登记、闪现、大乔第 4 槽、未知冷却、重复替换、无效输入、重新读取、撤销与清空；前端模拟测试覆盖提交、到期、移除和恢复。实际 Windows 游戏焦点与真实置顶窗口交互未在本轮实测。

## 多人指令与别名

支持“后裔小明都放大招了”“后羿和明世隐都开大了”“后羿、小明都闪现了”。后裔映射后羿，小明映射明世隐，猴子映射孙悟空。多人共用动作需使用“都”或“一起”，最多五个英雄名称；重复英雄合并。整句有未知名称、否定或疑问时不登记；达到记录上限导致失败也不会只保存部分英雄。

## 全英雄别名词库与确认

别名独立维护在 `resources/knowledge/hero_voice_aliases.json`，覆盖当前知识库的 132 名英雄条目，包含 304 条别名/错字映射（包括跨英雄共享项）。这是人工整理的初始词表，不保证覆盖所有外号，也不是已实测的语音识别准确率。少数英雄没有可靠的额外别名，保留空列表，仍支持官方名。重新生成语音冷却知识库不会覆盖这个文件。

例如香香→孙尚香、猴子→孙悟空、阿离→公孙离、后裔→后羿、赢政→嬴政。鲁班→鲁班七号/鲁班大师，百里→百里守约/百里玄策，元流之子→各职业，需要用户选择。官方完整名称优先；未知称呼提示重试，不做任意模糊猜测。

接口返回 `ok:false,status:needs_confirmation,candidates:[{heroes,label,text}]` 时尚未保存任何记录。面板与主工作台显示候选，用户点“确认”后提交对应完整名称指令才计时；多人指令确认完整组合。超过八个组合提示改用全名。取消或修改输入会撤下候选。未来 ASR 可直接复用同一解析接口和待确认状态；本次仍未接入麦克风。

## 报时延迟补偿

按用户确认，“没大招”“没大招了”视为刚使用大招，支持别名及“六耳小明都没大招”多人表达。此约定不扩展到“没有放大”“没学大招”等否定表达。新提交的文字/语音文字指令统一按基础冷却减去3秒计时，最少为0；未知冷却仍未知，原有记录不重新扣减。基础冷却值保留，计时记录通过估算释放时间和 `report_delay_s` 表达补偿。手动指定冷却和已过时间的登记接口继续以填写值为准。
