# 全英雄知识库补充记录 · 2026-09-23

## 结果

对用户确认范围内的132个英雄重新抓取腾讯官网制胜宝典，保存537条技能。吕布、夏侯惇、李白、关羽、牛魔、蒙犽的技能内容与原批次不同。每个英雄均补充官网使用技巧、对线反制、团战、出装及铭文说明，独立存为 `strategy_reference`，不覆盖原有5位英雄38条个人攻略。

别名词库包含469条映射（包括重复对应多个英雄的称呼），新增可追溯的官方称号及人工整理同音错字。所有132个官方名称保持直接匹配，共享别名继续先确认。词表覆盖不等于真实语音准确率，本次未接语音服务。

## 访问

打开 `http://127.0.0.1:8767/static/knowledge.html`，可用英雄名、别名或错字搜索并选择英雄。桌面面板“使用说明”中增加“打开全英雄知识库”；识别到英雄后的技能资料也增加可展开的打法与出装参考。

`GET /api/knowledge/heroes` 返回可搜索目录；原 `GET /api/knowledge/skills/{hero}` 同时返回 `voice_aliases` 和 `strategy_reference`。SQLite在来源改变后自动同步。新资料作为可查参考，不自动将未核验攻略变成本局事实或固定出装指令。

## 证据与边界

来源：腾讯官网英雄目录、各英雄制胜宝典JSON、装备目录。原始下载批次位于 `work/knowledge-snapshot-20260923-113734`。详细统计见同目录的 `full-knowledge-2026-09-23.json`。

官网未为所有内容标注当前正式服版本；例如廉颇的攻略提示仍有与技能正文不一致的旧数值。因此所有新增攻略均标记版本待核验，不能把抓取日期当作版本验证。装备编号1722、1225、91040、1223未在本次装备目录解析到名称，保留原编号并明确待核对。朵莉亚动态冷却、鲁班大师冷却冲突继续保留，未知数据不强制转为精确倒计时。

官网目录新增“王维”（138），本轮按已确认132英雄范围暂不加入计时支持，列为新增条目待核验。

## 更新流程

1. 运行 `scripts/refresh_full_knowledge.py` 下载现有支持范围的官方快照，失败时不发布部分资料。
2. 使用输出目录运行 `scripts/update_skill_catalog.py --source-dir <快照目录>`。
3. 将该目录 `items.json` 发布到 `resources/knowledge/equipment_catalog.json`。
4. 运行 `scripts/build_voice_knowledge.py` 和 `scripts/audit_hero_knowledge.py`，同步衍生冷却与审计。
5. 检查数据差异、保留原始快照并运行知识库/语音/计时回归测试后重新加载服务。

别名词库独立保存，更新技能资料不会覆盖人工别名。官网称号和错字条目仍需人工审核后维护，禁止自动生成任意模糊映射。
